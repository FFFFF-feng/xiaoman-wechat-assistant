# 分级提醒与跟进：本地开发记录

日期：2026-10-19。本轮继续完成规划第4步，尚未部署服务器，也没有给真实用户发送提醒或更新公告。

## 默认行为

| 日程优先级 | 提前提醒 | 到点提醒 | 后续进度询问 |
| --- | --- | --- | --- |
| 重要 high | 提前20分钟、10分钟 | 一次 | 间隔10分钟，最多两次 |
| 普通 normal | 提前10分钟 | 一次 | 间隔10分钟，最多一次 |
| 低 low | 无 | 一次 | 无 |

进度询问只在真实到点提醒或用户主动要求的稍后提醒被平台受理后安排，不能把入队当成送达。起点取实际开始投递的时间与事项时间的较晚者，不因结果晚回而把旧提醒重新当作刚发送。自动提前提醒和询问进度在北京时间22:00—08:00休息；用户明确设置的到点时间和“十分钟后再叫我”照常遵守。

新建两分钟后的短事项不会补发之前的20分钟/10分钟阶段；离线过久错过的阶段不集中补发。每个阶段最多容许迟到5分钟，同时继续服从原有投递器的最大迟到配置。

## 用户可以这样说

| 说法 | 结果 |
| --- | --- |
| 完成了完成了，你别催了 | 在上下文明确时完成当前事项，取消未发送的后续通知 |
| 还没完成 / 准备好了 / 正在做 | 只记录对话进度，不将任务勾为完成；下一句“做完了”仍可接上 |
| 别催我了 / 这件事先别催了 / Java作业别催了 | 暂停当前事项这一轮提醒，事项保持未完成 |
| 十分钟后再叫我 / 十分钟后再叫我Java作业 | 下一次通知改到十分钟后，原事项时间保持不变 |
| 恢复提醒 / Java作业恢复提醒 | 约定一条新的通知：事项还未到点时按原时间，到点已过则十分钟后；不重发旧投递 |
| 关闭提前提醒 / 开启提前提醒 | 保存本人的提前提醒开关，不影响别人的设置 |
| 关闭催促 / 开启催促 | 保存本人的进度询问开关，保留到点提醒 |
| 关闭自动跟进 / 开启自动跟进 | 同时关闭或开启自动提前提醒和进度询问；明确约定的稍后提醒仍保留 |
| 提醒跟进设置 | 查看服务开关和本人的两个偏好开关 |

任务指代优先使用刚实际提醒的事项，或者刚成功创建/改期的事项；没有充分上下文时询问任务名。候选选择保存15分钟，支持短任务名或“第一个”“第二个”。候选在等待期间被完成、取消或改期时不移位选择其他事项，而是重新确认。资料、引述、条件和疑问不会当作暂停或完成命令。

暂停只作用本轮提醒，不直接修改日程页面的提醒总开关；同一事项改到新的日期时间后，按新的安排重新计算。关闭日程里的提醒总开关会阻止所有通知，聊天不能在未重新打开总开关时承诺稍后投递。处于发送中的请求无法撤回；暂停/完成阻断的是尚未发送及之后的通知。

已经关闭而取消的某个自动阶段不会因为再次开启就立即补发；后续符合条件的阶段正常计算。单次阶段失败不自动重试，发送结果不确定则暂停整轮自动跟进，需用户明确恢复。晚到的受理结果不能覆盖用户后来暂停或延后的选择。

## 实现范围

- 新增`reminder_followup_plans`保存当前日期时间对应的轮次、暂停/延后/不确定状态和跟进起点。
- 新增`reminder_stages`保存阶段、原事项时间、轮次与唯一事件键。普通到点记录沿用原结构，提前/进度/延后通知附加阶段信息。
- 新增`reminder_followup_preferences`保存按用户隔离的提前与进度开关。
- 新增`reminder_action_requests`保存待确认的操作、候选事项及会话焦点，支持澄清后的简答。
- 复用原`/outbox`领取、开始、结果协议及45秒领取租约；120秒后仍无结果记为unknown，不自动重发。Node连接器协议和其他项目服务不变。
- 每次领取和开始发送前重新核对绑定、事项归属、状态、时间、轮次、优先级、开关及暂停状态。
- 现有`init_db()`仅新增表，不重建旧任务和历史提醒；临时SQLite文件验证升级及重新连接后仍保留暂停状态。

## 部署开关

`CLAWBOT_FOLLOWUPS_ENABLED`缺省为`false`，示例配置也保持false。这样把源码更新到服务器不会悄悄启用更多通知；须在手机验收和发布安排确认后，仅在本项目私有运行配置中显式设为true，且原`CLAWBOT_ENABLED`和`CLAWBOT_REMINDERS_ENABLED`也须开启。无需修改其他项目、共享Nginx或Node插件协议。

关闭总服务开关会阻断额外阶段；已明确暂停的事项不会因重启或关闭该开关而自动恢复。重新启用时，已经取消、失败或不确定的旧投递不复用；必要时由用户明确说“恢复提醒”约定新一次通知。

本轮不修改线上`web/releases.json`，不触发用户更新广播。真实手机收发、模型语言效果与上线后时间观察仍待灰度验收。
