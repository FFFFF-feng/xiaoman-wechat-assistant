# 成员与邀请管理后台

管理入口：自己的固定 HTTPS 域名加 `/manage`，例如 `https://schedule.example.com/manage`。电脑和手机浏览器都可操作。`/join` 是体验者入口，不是管理入口。

## 日常操作

1. 使用独立账号 `admin` 和部署管理员交付的管理密码登录。不要填写百炼密钥、微信凭据或内部桥接密钥。
2. 点击 **新建邀请**，填写体验者备注，例如“体验者甲”，不要填手机号或微信 ID。
3. 点击 **复制链接**，把完整专属链接私下发给这一位体验者。链接30分钟有效，每加一人重新生成。收到链接的人用本人微信扫码并确认连接。
4. 若对方需要手动填写，展开“对方需要手动填写邀请码？”，复制邀请码，填写页面仍为同一域名的 `/join`。
5. 体验者连接完成后发“你好，小满”“一分钟后提醒我喝水”“打开日程”，确认本人收到回复、提醒，并只能看到自己的任务。

邀请原始凭证只在签发成功的当前页面显示；关闭、刷新或退出后，无法从历史记录找回原链接。未保存时先在邀请记录中取消旧邀请，再生成新邀请，不能反复扫码已有用户。

## 页面功能

| 页面 | 操作 |
| --- | --- |
| 成员 | 搜索备注、筛选授权异常、查看历史任务数量、修改备注、撤销接入 |
| 邀请记录 | 查看最近100条邀请及接入/到期状态；取消尚未完成的邀请 |
| 操作记录 | 查看最近50条生成、取消、改备注与撤销操作，不展示聊天内容 |

“授权文件正常”只表示当前允许列表与本机原生凭据一致，**不是微信在线或手机已收到的保证**。扫码服务与提醒投递器状态单独显示，页面每30秒刷新，也可手动刷新。

修改备注不改变微信昵称、头像或任务归属。撤销需要二次确认：阻止新消息处理、使旧日程凭证失效，并拦截尚未开始的提醒；已经开始发送的消息不能追回。历史任务和聊天记录保留，不做数据删除。

授权缺失或不一致时先检查历史绑定和原生凭据，不能靠昵称猜测身份。后台不会自动改绑或迁移任务。重新授权也不自动继承旧身份任务；此类身份修复需要单独核对与备份。

## Linux首次启用

已完成独立运行目录初始化、插件安装和桥接激活后，以小满服务账号运行：

```bash
/srv/xiaoman/app/.venv/bin/python /srv/xiaoman/app/scripts/setup-clawbot-admin.py \
  --root /srv/xiaoman/runtime
```

脚本生成随机独立管理密码，只在私有 `admin-login-*.md` 中交付，终端仅显示文件路径；创建密码哈希文件与 `CLAWBOT_ADMIN_AUTH_FILE` 配置，保留其他模型/微信配置。文件权限为600，备份目录为700。已有密码默认不覆盖。

管理员首次启用后只重启小满后端与网页代理，不重启整台服务器或其他业务：

```bash
sudo systemctl restart xiaoman-backend xiaoman-web
```

若现有 Nginx 按精确路径放行，在已有小满域名内额外代理 `/manage` 和 `/api/manage/` 到白名单网关 `127.0.0.1:18084`，不要代理到Python业务端口或放开内部接口。保持原有回调/日程/接入页。备份当前配置并执行 `nginx -t` 后再reload。新独立域名的模板见 [Nginx配置](../deployment/nginx/xiaoman.conf.example)。

公网冒烟：`/manage`返回200；未登录访问 `/api/manage/overview`返回401；`/api/internal/clawbot/health`、`/docs`仍不可访问。没有配置管理密码时管理接口返回503，不回退到内部桥接密钥。

## 密码重置与安全边界

```bash
/srv/xiaoman/app/.venv/bin/python /srv/xiaoman/app/scripts/setup-clawbot-admin.py \
  --root /srv/xiaoman/runtime --rotate
```

重置前备份原配置，生成新的私有密码说明，旧会话在下一次请求时失效。配置路径不变时无需重启服务。历史密码说明与备份仍属敏感文件，应按公司的凭据保管规范处理，不公开分享。

- 当前为一个部署级管理员账号，不是多人角色/权限系统；管理密码只交给授权管理员。
- 密码保存为随机盐PBKDF2哈希。会话仅在浏览器/后端内存，最长1小时；刷新页面或后端重启需重新登录。
- 会话和密码不写入地址栏、Cookie或浏览器存储；公共页面不返回成员信息。
- 登录限制每分钟最多10次（当前单进程全局计数），避免无界密码计算；不代表已做完整抗攻击压测。
- 管理 API 拒绝非本项目Origin；白名单网关不转发跨域放行头。不向公网开放通用RPC、配置或原始微信身份。
- 原始邀请仅签发一次，使用请求编号持久去重；操作不确定时先刷新记录，不自动重复写入。
- 没有删除历史任务、导出聊天、自动修复身份或自动修改微信资料功能。

基础部署与备份见 [Linux运维](DEPLOYMENT.md)，用户体验与终端备用工具见 [用户接入](USER_ACCESS.md)。
