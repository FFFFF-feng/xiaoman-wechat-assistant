# 自然表达抽查（合成输入）

日期：2026-10-16。使用项目现有模型配置，输入均为人为构造的聊天、两条资料和一张通知图片。没有读取真实用户会话、连接数据库或发送微信。本次验证的是现有模型回复，不是 ACP 中的 Codex。

首轮普通闲聊没有取得有效结果，其他三项路由/事实检查通过。但人工检查发现：周报建议自行填入“整体进展正常”“1个事项待确认”，通知图片额外评价“时间还早得很”。自动事实关键词通过不代表语气或内容合格。

因此增加了具体的操作起点示例，明确不填造用户进度；通知直接说已知事实，不增加日期远近的评价。调整后复查了聊天、规划和图片三项，均取得有效回复，人工对照未发现上述两类问题。聊天首轮失败原因未确定，单次复查成功不代表稳定性问题已经解决。

| 输入 | 调整后实际输出 |
| --- | --- |
| 今天事情好多，有点不知道先干哪个 | 可以先别追求从哪件开始最完美，只挑一件“不做会最影响后续”的事。先做二十分钟，通常能把一团乱的感觉压下去。 |
| 帮我想想周报怎么开始，先不要创建提醒 | 可以先花10分钟列出本周做过的三件事，再给每件事补一句结果或影响，这样周报开头就不会太空。 |
