## 用户流程

1. 用户打开自己的邀请链接，扫码并完成微信授权。
2. 连接成功页面立即提供 `/guide` 使用指南入口。
3. 用户回到本次授权的 ClawBot 对话，发送「你好，小满」。
4. 首次可信消息到达后，网关自动发送一次「点击查看小满使用指南」Markdown 链接。网关每 5 秒检查队列，实际到达时间仍取决于微信通道。
5. 用户按指南保存头像，在 ClawBot 设置中选择头像、保存「小满」备注名，并逐条体验聊天、提醒、待办、语音、日程和资料整理。

以后发送「使用指南」「新手指南」或「初始化小满」均可再次获取链接。初次扫码后没有发消息时，不直接尝试推送：微信渠道可能尚无可用回复上下文，扫码授权成功不等于消息通道已经验证。

## 页面与品牌素材

- `/guide` 是不需要登录的公共帮助页，不包含个人任务、账号标识或授权令牌，可以分享。
- `/static/xiaoman-avatar.jpg` 保留原公开地址，现已返回选中的PNG原图（`web/xiaoman-avatar.png`，`Content-Type: image/png`，内联文件名「小满头像.png」），不转码、不裁剪。页面使用版本查询参数、图片禁止缓存；网关仅对这个头像地址透传文件名响应头。不会新增公网路径，也不需要修改共享Nginx。公网原图字节哈希已验证与A版一致。**更新指南素材不会更改用户已经设置的微信头像**。
- 保存图片、复制名称和示例均不自动执行微信操作。每位用户自行在 ClawBot 的设置里确认，不能同步到其他用户，不改个人微信资料。
- 浏览器允许时按钮复制文字；拒绝剪贴板时显示文字框，让用户长按复制。微信若不支持下载按钮，可打开原图并长按保存。
- 页面不调用任何业务 API、不使用第三方脚本/字体/分析工具。CSS、JS 捆绑进 HTML，使用精确哈希 CSP。
- 当前指南面向ClawBot显示设置；服务号的正式头像和名称由管理员在公众号后台统一设置，不要求关注者自行修改。
- 语音和资料识别依赖部署方启用对应配置；页面提示限制，不假称未配置的能力可用。功能示例会在用户粘贴发送后创建真实测试待办。

## 发送实现与安全

- 绑定完成同一事务中创建 `clawbot_welcomes`，按账号＋发送者的稳定 owner 唯一。重复完成授权不重复创建，不向升级前已绑定的用户批量补发。
- 状态：`waiting → pending → claimed → sending → accepted / failed / unknown`。
- 只在已鉴权、允许名单匹配的入站消息后激活；没有公网 HTTPS 地址时保持待发送。
- 网关使用原有腾讯渠道 `sendText` 适配器，不读取微信私有凭据；领取和发送前再次核对绑定账号、收件人。
- 未开始发送的领取超过 45 秒可以恢复；发送开始后超时或结果不确定不自动重发，用户可发「使用指南」手动获取。
- `accepted` 仅表示平台受理，不证明手机收到。撤销后禁止开始发送，未发送记录不会绕过绑定校验。
- 欢迎消息使用独立队列，不生成提醒或任务，不影响正常提醒投递器。任务和个人日程授权保持原有隔离。

本次已同时更新 Python 后端和网关插件源码，并预先备份数据库、源码、私有状态与本项目 Nginx 配置。后续升级仍按原部署流程备份、停止并启动对应服务。`init_db()` 用 `create_all` 新建独立欢迎表，不删除旧表或任务。不要直接修改数据库旧记录制造欢迎。旧回调与其他公司的业务配置保留。

若 Nginx 使用精确路径代理，在已有域名内额外放行 **GET `/guide`、`/static/xiaoman-avatar.jpg`** 到路径白名单网关 18084。禁止公网代理 `/api/internal/clawbot/welcome/*`；不要覆盖原售后服务或现有 server block。JS 和 CSS 已内嵌，无须放行 `/static/guide.js` 或 `/static/guide.css`。
