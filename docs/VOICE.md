# 微信语音与意图识别

更新：2026-10-12。语音代码与离线回归已完成；百炼真实转写接口已调用成功。微信手机端整条语音链路仍需用户实际发送验收，不把API成功写成微信验收通过。

## 处理路线

```text
微信语音
  ├─ 腾讯插件已提供转写 → 原有文字意图入口
  └─ 只有音频 → 腾讯插件下载/转码WAV → 可信媒体钩子
                 → 内部/voice → 百炼ASR → 现有聊天/任务/日程逻辑
```

`before_dispatch`在固定宿主2026.10.1里不直接提供媒体字段。连接器用`message_received`保存与账号、发送者、消息编号匹配的媒体事实，90秒有效、最多500条；不会从用户文字提取文件路径或下载任意URL。只有当前语音的单个WAV附件可以进入ASR，引用、混合附件和未完成暂存的附件拒绝执行。

识别后回显原始文字，便于用户纠正。“查询代办”等少量完全匹配的只读查询会按“查询待办”处理，不自动改写任务标题、日期或时刻。任务仍经过原有否定/条件提醒、日期、时间与归属检查。ASR不准确时可能造成错误理解，使用后务必核对回复；涉及重要事项请用文字确认。

## 配置与启用

全新初始化默认`ASR_ENABLED=false`，不会自动启用计费服务。在已激活的独立小满目录中执行：

```bash
/srv/xiaoman/app/.venv/bin/python /srv/xiaoman/app/scripts/setup-clawbot.py features \
  --root /srv/xiaoman/runtime --enable-speech
```

该命令初始化本地“小满”名称、猫爪图标及IDENTITY.md，启用ASR开关，保留模型、密钥和绑定。原文件备份到私有`state/xiaoman/feature-backups/`，不会启动进程或修改微信联系人资料。已有其他Agent时拒绝猜测改哪个身份。

私有`runtime.env`可配置：

```dotenv
ASR_ENABLED=true
ASR_MODEL=qwen3-asr-flash
ASR_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
ASR_API_KEY=私下填写同地域百炼密钥
```

不把密钥贴入Git、截图或终端历史。未单独设置ASR密钥时可使用`DASHSCOPE_API_KEY`/`ALIYUN_API_KEY`，或仅在聊天模型与ASR使用相同百炼基础地址时复用`MODEL_API_KEY`；不会把其他厂商的模型密钥发送百炼。当前ASR只接受文档列明的百炼北京/国际/美国基础地址，不支持任意代理地址或任意模型。模型权限、地域与计费由百炼账号决定。

变更后暂停扫码，按部署文档重启本项目后端和微信网关，再恢复扫码worker；不重新扫码既有用户。Windows已有独立安装使用相同`features`命令、实际本机运行根目录，以及本机已配好的启动/停止脚本。

## 限制与安全

- WAV单声道、16位PCM，采样率8～48kHz，最多120秒且4MiB以内；实际微信客户端限制可能更短。
- 未转码的SILK、图片、文件、视频和合并聊天记录不支持；不修改腾讯插件源码绕过限制。
- `/api/internal/clawbot/voice`需要私有桥接鉴权和真实绑定，公网白名单拒绝此路径。
- 每用户每分钟最多10条新ASR请求，原有业务消息限流也保留。识别失败/超时不自动重试，不以默认Agent补答。
- 在请求云服务前保存消息处理状态；重复投递不再次识别或重复执行任务，账号与发送者共同参与去重。
- ASR等待后重新检查撤销状态；撤销后不继续执行任务。失败或结果不确定时先查询待办，不连续重发创建请求。
- 原始音频只在请求内存中使用，小满数据库保存识别文字、摘要和处理状态；官方微信插件可能缓存媒体文件，需按公司策略审查清理与保留周期。
- 语音会发送百炼，识别后文字还可能发给聊天模型；发送语音前需了解数据用途和计费，不输入敏感资料。

## 验收

离线测试覆盖有效/无效WAV、静音、外部路径/URL拒绝、身份隔离、重复语音、ASR失败、撤销、否定/条件提醒与只读同音容错。最新全套结果记录在README。

真实百炼探针使用本机合成的固定短语“查询待办”，约1秒返回“查询代办。”；只读容错已覆盖此结果。该探针没有向任何微信用户主动发送消息，不等于手机完整链路已验收。

手机分别发送：语音“查询待办”、语音“两分钟后提醒我喝水”、语音“不要提醒我明天十点写周报”、语音“打开日程”。核对识别回显、任务只创建一次、提醒只到本人、否定不建任务、日程单击正常。再验证第二位用户隔离、断网和重启恢复。

接口依据：[腾讯微信协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol_zh_CN.md)、[百炼录音识别接口](https://help.aliyun.com/zh/model-studio/recording-file-recognition-qwen)。
