# 小满名称、头像与微信资料边界

更新：2026-10-12，依据本机官方微信插件2.4.10及[官方协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol_zh_CN.md)。

| 位置 | 当前能力 |
| --- | --- |
| 小满聊天人设/业务回复 | 由Python小满负责，不使用OpenClaw默认人设回退 |
| 接入页与日程页 | 项目控制的网页，可以统一“小满”和项目图标 |
| OpenClaw本地Agent身份 | 新部署初始化为“小满”、猫爪图标和IDENTITY.md，仅本地后台元数据 |
| 手机微信中的ClawBot名称/头像 | 当前官方插件公开接口没有自动设置该资料的入口；不当作已实现 |

`scripts/setup-clawbot.py init`会生成本地 `workspace/IDENTITY.md`、`avatar.svg` 和Agent identity；**不会修改用户微信上的联系人头像或名称**。微信协议的 `bot_agent` 是日志/监控标识，不是微信昵称；不能通过修改它实现联系人改名。

用户若在自己的微信客户端有资料/备注编辑入口，可按客户端实际界面手动调整；当前不保证各版本都具有同一设置入口，也不声称能统一修改所有用户的联系人资料。不要将二维码、绑定Token或私有接口交给不明改名工具。

下一步候选开发：接入后显示明确的品牌说明与功能指引；首次有效入站后的欢迎语；接入自测状态与用户确认。欢迎语必须等待有效绑定和官方上下文，不能在扫码成功后盲目主动发送并宣称已送达。平台若后续提供正式资料接口，再单独实现和实机验收。
