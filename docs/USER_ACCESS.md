# 邀请制多人使用

更新：2026-10-12。用户最新反馈多位体验者能正常使用功能；既有两位聊天/日程隔离和本人到期提醒通过。公司常驻部署、隔夜稳定性、真人撤销与每位用户完整验收仍待验证。模拟身份不算真人验收。

## 用户怎么加入

1. 管理员分别签发邀请。所有人使用同一个 HTTPS `/join` 页面，邀请凭证各不相同、30 分钟有效。
2. 打开自己的邀请，阅读数据用途并同意，生成本人连接二维码。
3. 本人微信扫码并确认。微信显示配对数字时填到接入页；过期二维码由官方插件刷新。
4. 授权完成后，在微信 ClawBot 对话发送“你好，小满”“一分钟后提醒我喝水”“打开日程”，确认回复、本人收到提醒和日程能打开。
5. 邀请有效期内可从原页面撤销；到期后联系管理员。撤销阻止新消息与未开始的提醒发送，旧日程失效，历史任务保留。已开始发送的消息无法追回。

已接入微信不要重复扫码：官方插件可能清理同一扫码者的旧凭据。当前拒绝覆盖/自动迁移旧绑定，误扫后需管理员检查。

这是各用户分别授权同一个部署实例，不是一个可共享的永久微信好友二维码。用户不需要填写 IP 白名单、模型密钥或操作服务器。聊天内容会发送到项目配置的大模型，请勿输入密码或敏感资料。

## 日常怎么用

在本人授权后出现的ClawBot对话发送文字，不要发给旧公众号或另一个机器人入口：

| 功能 | 示例 |
| --- | --- |
| 聊天 | `你好小满，今天有点累` |
| 短时提醒 | `两分钟后提醒我喝水` |
| 指定时间 | `明天上午十点提醒我提交周报` |
| 查看任务 | `查询待办`、`今天有哪些任务` |
| 修改/取消/完成 | `把周报延后到明天下午三点`、`取消喝水任务`、`完成周报` |
| 手机日程 | `打开日程`，单击“点击打开我的日程” |
| 语音意图 | 启用ASR后发送微信短语音，如“查询待办”“两分钟后提醒我喝水”；核对识别文字 |
| 小满身份说明 | `小满资料`，查看项目名称、图标及微信端资料限制 |

同名任务有歧义时按追问补充，不连续重复创建。未写日期但指定时刻默认当天，已过时间会追问；条件提醒、图片/文件和合并聊天记录尚未支持。语音代码与百炼接口验证完成，手机完整链路仍需实测，详见[语音识别](VOICE.md)。日程链接30分钟有效，只限本人；失效后重新发“打开日程”，不要转发。

## Linux管理员直接生成邀请

完整安装见 [Linux部署](DEPLOYMENT.md)。服务器私有终端执行，替换实际域名，并给每个人用新的输出文件：

```bash
/srv/xiaoman/app/.venv/bin/python /srv/xiaoman/app/scripts/manage-clawbot.py invite \
  --token-file /srv/xiaoman/runtime/state/xiaoman/bridge.key \
  --label '体验者A' --public-url https://schedule.example.com \
  --output /srv/xiaoman/runtime/state/xiaoman/invite-A.json --show-link
```

`--show-link`直接显示完整专属链接，复制给该用户即可，不必另填邀请码；不加则仅保存私有JSON。不要公开带凭证的截图，也不要代用户扫码。服务须在线，扫码worker未就绪时开始扫码会拒绝。

## 功能结构

| 组件 | 职责 |
| --- | --- |
| Python 单进程后端 `18083` | 邀请哈希、名额、扫码租约、绑定追加/撤销、独立任务与历史 |
| 白名单网关 `18084` | 只开放接入页、邀请认证操作和日程，不暴露内部管理/聊天/调试 |
| 微信 Gateway | 腾讯插件多账号收发，按账号、渠道和对端隔离会话 |
| `enrollment-worker.mjs` | 串行调用官方 `channels login`，处理二维码/配对数字，从官方本机凭据确认账号和扫码者后提交绑定 |
| `xiaoman-reminders` | 按 owner 选精确微信账号和收件人，发送前重新检查任务与绑定 |

接入页不能自选身份或调用注册管理接口。邀请仅存哈希，配对数字只在短期内存消费一次。本接入器不输出微信 Token、原始身份、二维码 URL 或配对数字；官方插件私有日志仍需限制访问。

## 管理员准备

私有环境启用 `CLAWBOT_ENROLLMENT_ENABLED=true`，默认 `CLAWBOT_MAX_USERS=10`。准备私有桥接密钥、可信 `bindings.json` 和已安装的官方插件；不要每次启动从原生凭据重新生成绑定，否则会重新放行被撤销者。

必须运行单个 Python 后端进程，保持 `session.dmScope=per-account-channel-peer`。微信 Gateway 只监听回环、启用鉴权、关闭控制页面及 Agent 工具。

Windows 本机已有独立安装时启动扫码 worker：

```powershell
.\scripts\Ensure-ClawbotEnrollment.ps1 -LocalRoot '你的独立ClawBot运行目录'
```

停止时追加 `-Stop`，只终止验证归属后的 worker 及其扫码子进程，不删除数据或停止其他服务。本机已有“小满启动”会联动启动该 worker。公司 Linux 需把同一 Node worker 配成受控常驻服务，并设置 `XIAOMAN_LOCAL_ROOT` 指向独立运行根目录，准备 `state`、`npm/node_modules/openclaw` 和官方插件；不能照搬本机私有目录到公开仓库。

## 签发和撤销

当前本机无需输入命令：先双击“小满启动”，再双击独立运行目录的“生成小满邀请.cmd”，填写体验者备注。窗口会直接显示新邀请的完整 HTTPS 链接、邀请码及北京时间到期时间，同时把完整链接复制到剪贴板。直接粘贴完整链接给这一位用户，无需另填邀请码；每添加一人重新生成。剪贴板失败时可手动复制窗口内的链接。邀请页也提供“复制本邀请链接到手机”。不要把 `127.0.0.1` 地址或电脑的文档路径发给手机。

桌面“小满接入测试”及 `Start-Clawbot.cmd` 采用后台启动，关闭提示窗口不停止聊天。邀请脚本也会自动启动缺失的聊天通道，等待加载并防止重复启动；冷启动可能较慢，不需要重新扫码。电脑须保持联网、不休眠；关机后需再次启动。`生成小满邀请.cmd -CheckOnly` 仅检查启动进程，不签发邀请或修改剪贴板。

示例路径与域名需要替换。管理工具只访问 `127.0.0.1`，默认不在stdout输出邀请码；显式加 `--show-link` 才显示短时邀请：

```powershell
.\.venv\Scripts\python.exe scripts/manage-clawbot.py invite `
  --token-file '你的私有目录/bridge.key' --label '体验用户一' `
  --public-url 'https://join.example.com' --output '你的私有目录/invite-user-one.json'
```

只把生成文件的 `url` 发给对应用户；它含短时凭证，不提交 Git、不公开发群、不自己先扫码。每份邀请只绑定一人。公司域名只反代到白名单网关，`PUBLIC_BASE_URL` 使用固定 HTTPS。本机临时隧道用于联调，重启/断网可能换域名，不是正式长期入口。

列出成员标签、身份哈希和扫码服务健康状态：

```powershell
.\.venv\Scripts\python.exe scripts/manage-clawbot.py members --token-file '你的私有目录/bridge.key'
```

用返回的 `member_id` 撤销，不能使用微信原始 ID：

```powershell
.\.venv\Scripts\python.exe scripts/manage-clawbot.py revoke `
  --token-file '你的私有目录/bridge.key' --member 'clawbot:替换为成员哈希'
```

## 验收范围与限制

已自动验证：任务/历史隔离、相同消息编号与不同账号隔离、跨人日程操作拒绝、提醒账号/收件人准确、原子追加与幂等、邀请/租约过期、取消、单人邀请串行排队、配对数字消费、撤销与旧日程失效。浏览器使用模拟扫码状态检查界面，不能冒充实际扫码。

第二个真人必须验证：授权、Gateway 加载新账号、两人同时聊天、不同任务、两条真实提醒只到本人、日程隔离、断网/重启恢复和撤销。页面“已完成授权”不等于实际收到微信消息。

尚未提供：匿名公开注册、网页账号系统、自助导出/删除、每日模型成本硬上限、账号轮换迁移、生产高可用。已有每用户每分钟 30 条新消息限制、默认 10 个绑定名额。扫码超时或结果不明不自动重试原生登录，需新邀请或管理员核对。

## 常见问题

- 找不到邀请码：优先用管理员发的完整 `https://实际域名/join#invite=...` 链接，无需另填码；裸 `/join` 才要输入。过期/取消/撤销的邀请不要重复用。
- 手机打不开：不能使用127.0.0.1、电脑文件或旧临时隧道；检查固定域名、证书和四个服务，不公开日程令牌。
- 授权后没回复：本人发新纯文字，再用 `/echo 7313` 与正常账号对照；原生也不回不能立即认定模型失败/邀请错人。
- 没有到期提醒：先确认任务确实创建、没有过期/取消且通道在线；即时回复不算提醒验收。
- 关闭启动窗口：本机后台仍可运行，但电脑休眠/关机不能发提醒；公司systemd部署不依赖个人电脑在线。
- 微信联系人名/头像：公开插件接口当前不能自动修改；本地“小满”身份不等于微信端改名，见 [品牌边界](BRANDING.md)。
