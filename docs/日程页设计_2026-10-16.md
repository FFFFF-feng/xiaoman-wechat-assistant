# 小满日程页改版

目标：参考小红书 CATO 的轻松、明亮与宠物陪伴感，提供用户自己安排和调整日程的完整入口。已看见公开文章首图的浅色聊天背景、猫咪和粉色强调；轮播进一步读取超时，不能宣称看过对方完整表单或测试过其产品。小满保留自己的品牌，不复制对方图案和名称。

## 设计约定

- 纸粉 `#FFF7FA`：页面底色；白色 `#FFFFFF`：日程与表单；莓粉 `#BC3565`：主要操作与选中日期；浅粉 `#F9E4EC`：日历与陪伴区；深紫灰 `#382D3C`：正文；草绿 `#3D7863`：完成状态。
- 中文使用系统的苹方、微软雅黑和 Noto Sans SC；数字使用 Segoe UI。无额外字体下载。正文14至16px、标题24至30px，手机触控区至少44px。
- 桌面为日历侧栏和当天清单；手机为顶部陪伴区、可切换周/月日历与当天安排。新建按钮始终可见；表单用抽屉式弹层，在手机上成为底部面板。
- 记忆点是一只趴在日程纸上的原创小猫。其余装饰保持克制，不用深色宇宙背景或与日程无关的统计卡片。

```text
小满的日程簿                         + 新建日程
┌────────────────────────────────────────────┐
│ 今天的日期 / 一句轻松提醒 / 实际完成进度    小猫 │
└────────────────────────────────────────────┘
┌ 日历 / 周月切换 ┐ ┌ 当天安排 / 搜索 / 状态筛选 ┐
│ 日期选择与跳转  │ │ 时间、事项、分类、优先级    │
│ 快速记录入口    │ │ 完成、编辑、延后、取消      │
└────────────────┘ └───────────────────────────┘
                  新建/编辑：事项、日期、时间、分类、
                  优先级、备注、微信提醒或仅记录
```

评审：浅粉符合参考明确给出的方向；避免把所有区域做成相同圆角卡片，也不增加假统计、未实现的重复规则或不可保存的设置。完成进度只使用当前日期的真实任务计算。缺失链接、空列表、搜索无结果和保存失败分别给出下一步。

## 功能与验证范围

本轮实现页面创建/编辑、日期时间选择、分类、优先级、备注、仅记录开关、周月切换、搜索与筛选；已有完成/延后/取消继续保留。创建沿用个人短时授权并增加请求去重；编辑校验所属人与版本，避免覆盖别处的修改。仅记录的任务不会进入提醒调度或尚未开始的投递。

预览使用独立内存数据库和合成任务，不接入微信，不读线上任务。已检查电脑及390px手机视图，实际完成新建、设置分类/优先级/备注/仅记录、回显后改期、搜索、标记完成、已完成筛选、切换月历、跨月空状态和日期跳转。手机没有横向溢出。真实微信内置浏览器仍待上线后验收；预览环境不会验证真实平台提醒送达。

本轮完整离线检查：Python219项、微信连接器Node69项通过，其中新增13项后端用例覆盖保存、防重复、归属、版本冲突、提醒开关、已入队提醒停发及旧数据库迁移。401链接保护沿用原有授权检查，新增创建/编辑接口同样必须携带有效授权。

## 数据与接口

- `Task` 增加 `category`、`notes`、`reminder_enabled`；SQLite启动迁移为已有任务补默认值：生活、空备注、提醒开启，保留原任务及其优先级。
- `POST /api/schedule/tasks`：由短时链接解析owner，拒绝客户端指定owner；创建请求包含UUID，数据库按owner及UUID去重，内容冲突返回409。
- `POST /api/schedule/tasks/{id}/edit`：更新事项、日期时间、分类、优先级、备注和提醒选择；用`expected_updated_at`及任务状态做原子更新，拒绝旧版本覆盖。
- “仅记录”可以补记过去的事；开启微信提醒必须选择将来时间，并继续通过既有发送资格检查。关闭提醒后，调度器和未开始的投递会跳过该任务；已经发送的信息不能撤回。
- 原有完成、延后一小时和取消接口保留。修改请求不自动重试；不确定结果要求刷新核对，列表GET可做有限重试。
- 网关仅增加准确匹配的新建和编辑路径；数据库、普通本地任务API和内部桥接仍不公开。

## 本机预览

```powershell
python scripts/preview-schedule.py --port 18087
```

打开 `http://127.0.0.1:18087/schedule#access=preview-only-no-real-account-xxxxxxxxxx`。这是明确的合成预览标识，不是用户真实日程令牌。预览脚本单独设置禁用模型、微信和投递的环境，只创建内存数据库，没有运行调度器；关闭进程即结束本次预览。

截图保存在被Git忽略的 `output/playwright`。本轮改动尚未部署服务器。部署时需同时更新后端、页面和网关，再运行数据库初始化；不能只替换CSS而遗漏保存接口和提醒开关。
